# Typing Quest downloads

Typing Quest is an offline desktop typing adventure by Western University CS2212A Team 13. Download the compiled game from the [release page](https://github.com/yanglluo/typing-quest-downloads/releases/latest).

| Platform | Download | Start the game |
|---|---|---|
| Windows x64 | [Windows ZIP](https://github.com/yanglluo/typing-quest-downloads/releases/latest/download/TypingQuest-win.zip) | Extract the ZIP and double-click `run.cmd`. |
| Apple Silicon Mac | [Mac ZIP](https://github.com/yanglluo/typing-quest-downloads/releases/latest/download/TypingQuest-mac-aarch64.zip) | Extract the ZIP, open Terminal in the extracted folder and run `sh run.sh`. |

Install **Java 23 or newer**. Extract the entire ZIP to a writable folder and keep the files together. For a first playtest, select **Create example accounts** and sign in as `knight` with password `quest1234`. Saves stay in the extracted folder.

This page hosts the compiled playtest builds and download instructions. The Windows build was checked on macOS and still needs a native Windows playtest.
